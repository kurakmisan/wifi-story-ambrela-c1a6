One Wi-Fi network name that tells a whole story in 30 characters: **"Dad Changed Password, Mom Left"** — a dad changes the Wi-Fi password, and the mum walks out over it. Situation, characters and consequence in a single line a stranger reads in a phone's network list. `main.py` writes that single name (30 characters) to `/output/entry.txt`. Standard library only, no input, no network, same bytes on every run.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
WIFI_OUTPUT_DIR=./out python3 main.py   # or write ./out/entry.txt
```
